  • 紧急调度：优先级 ≥ 80 立即生成快照
  • 音频来源：区分 microphone / system_output
MILESTONES

里程碑完成情况

A0–A1：原系统复现与链路理解 完成

完成 JoyAI-VL 权重部署、vLLM、Live Adapter 与 WebUI 真实链路复现；验证 RTSP 视频流和模型自主输出机制。

A2：持续音频入口 完成

浏览器持续发送 40ms PCM16 小包；服务端使用 30 秒环形缓冲，并统计丢包、乱序、重连与时钟漂移。30 分钟模拟数据量测试保持内存有界。

A3.1：流式 ASR 框架 完成

实现 400ms 调度、6 秒滑动窗口、stable prefix，以及 speech_start / partial / stable / final / end 事件。

A3.2：真实 Qwen3-ASR 完成

使用 Qwen 官方服务包装器和独立 vLLM 0.14 环境，支持服务错误隔离、重试和重启恢复。官方中文样本完整识别。

A3.3：CLAP 环境声音检测 完成

增加火警、烟感、玻璃破碎、爆炸类别及 speech / music / background 负类；完成 16kHz→48kHz 支路重采样、阈值和冷却机制。

A4：统一多模态时间轴 完成

完成 OmniOrchestrator、固定 tick、priority 快照、会话回放 API、统一服务器单调时钟和跨模态事件排序。

A5：主动多模态决策 准备中

GPU0 暂不可用；可先用假 VLM 实现上下文构建、动作协议、冷却去重、打断和决策记录，再进行真实主模型验收。
